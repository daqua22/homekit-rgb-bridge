# Troubleshooting

Start with the local panel's status and Diagnostics. Fixed event logs are in the private profile's `events.log` (one rotated file, 256 KiB each). Do not share pairing/admin handoffs, config/state/HAP storage, QR images, raw serials or private paths. Third-party DEBUG output may be sensitive; leave it unset.

| Symptom                                        | Action                                                                                                                                                                                                                                                               |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RAM missing in OpenRGB                         | Install official signed PawnIO as instructed by OpenRGB; close iCUE/other RGB tools and run OpenRGB as administrator. Inspect its I2C/SMBus warning. Bridge code cannot discover RAM that OpenRGB does not detect.                                                   |
| OpenRGB detects devices but bridge does not    | Check OpenRGB backend and matching loopback SDK host/port; start SDK Server. Mock mode only lists its virtual light.                                                                                                                                                 |
| Device discovery fails                         | Check SDK connection, supported protocol (3+), timeout, local permissions and malformed-response errors. No low-level drivers or dangerous fallback probes are implemented.                                                                                          |
| Device is ineligible                           | Read its capability reason. Require per-LED Direct mode and matching nonzero LED/color counts. Identical devices without unique serial/location are rejected.                                                                                                        |
| Zone cannot be selected                        | Opt into experimental zones only if appropriate. Empty, duplicate-name, global-only or incomplete-partition zones remain unsupported. Listed zones are not a physical support guarantee.                                                                             |
| Configuration will not save                    | Confirm Save, valid names/ports, one or more members per group, maximum 100 enabled lights, matching backend IDs and no overlapping standalone/group/whole/zone targets. External edits require a refresh. Original config is not overwritten on validation failure. |
| Port already used                              | Stop the other bridge or choose a distinct HomeKit port. 51826 is default; an existing 51827 profile stays 51827. The admin panel prefers 8787 and falls back to a free loopback port.                                                                               |
| Launcher missing files                         | Extract the whole portable ZIP, keeping runtime/node.exe, node_modules, public and dist together. Do not launch from inside the ZIP.                                                                                                                                 |
| Hidden launcher blocked                        | Check Windows Script Host policy and downloaded-file warnings. Verify checksum/source. Do not disable organization security policy; the VBS startup mechanism is unavailable where scripts are prohibited.                                                           |
| Application cannot start                       | Stop older CLI/tasks using the same data folder. Select the correct existing profile and inspect NTFS access. An interactive launcher reports nonzero launch failure. Source users can inspect console errors.                                                       |
| Lock after crash                               | Wait at least 10 seconds; launcher retries briefly. Live legacy PID markers are respected. If PID reuse/permission ambiguity prevents recovery, inspect the process before removing any lock. Never delete a live bridge's lock.                                     |
| Panel says unauthorized                        | Reopen Launch-Bridge.vbs with the same profile or its private open-control.html. A bare URL/new browser tab has no API capability. Never paste the private launch URL/token into support.                                                                            |
| Home cannot discover bridge                    | Same trusted LAN, PC awake, no guest isolation/VPN interference; HAP TCP and mDNS UDP 5353 permitted. A localhost SDK connection does not establish iPhone reachability.                                                                                             |
| Pairing unavailable while stopped              | Start the bridge. Pairing status and private reveal are available only while its HAP instance runs.                                                                                                                                                                  |
| Need a factory reset                           | Remove the bridge from Apple Home first. Use the exact confirmation-protected reset procedure, then Quit/reopen. Do not reset keys to fix networking.                                                                                                                |
| Partial group failure                          | Read failed and accepted member targets. Some physical output may already have changed; no rollback or all-member success is claimed. Restore connectivity before issuing further commands.                                                                          |
| Colors change back / zones interfere           | Stop competing RGB apps/SDK clients. The bridge preserves other LED bytes but firmware isolation is unverified. Disable zone mode and test whole-device control if the controller cannot isolate zones.                                                              |
| Off still uses power / brightness is nonlinear | Expected: off sends black; brightness scales channels. Neither cuts power nor measures actual light output. Device gamma and firmware vary.                                                                                                                          |
| Configuration saved but restart fails          | The confirmed config and backup remain. Correct the HomeKit port/interface/permissions in the panel; pairing keys are not reset.                                                                                                                                     |
| Autostart points to an old folder              | Open the new package and correct profile; disable/re-enable sign-in startup. The path is per-profile and user-scoped. OpenRGB must start separately.                                                                                                                 |
| No control after sleep/reboot                  | Check OpenRGB, startup settings, process, network and lock status. Physical lifecycle testing is pending; no control is possible while PC is off/asleep.                                                                                                             |

Read-only PowerShell diagnostics:

```powershell
Get-CimInstance Win32_PhysicalMemory | Select-Object Manufacturer, PartNumber
Get-CimInstance Win32_SystemDriver | Where-Object { $_.Name -match 'Pawn' } | Select-Object Name, State
Get-NetTCPConnection -State Listen -LocalPort 6742,51826,51827
```

Inspect outputs privately and share only necessary model/version/status fields. Report bridge version/commit, Windows/OpenRGB version, steps and expected/observed behavior. Use the hardware form for device-specific observations.
