HomeKit RGB Bridge

Bring your PC lighting into Apple Home.

Dashboard

Devices & zones

Select a whole device or its individual zones. Save before starting new lights.

Zones require a valid per-LED layout. Firmware may still limit isolation. Zero-LED or ambiguous zones are unavailable. Direct mode replaces existing effects.

Logical groups

Choose targets that are not enabled as separate lights. A failed member makes the group command fail; diagnostics identify accepted and failed targets.

Test enabled lights

These are desired software values, without physical readback. Off sends black; brightness scales RGB channels.

Apple Home

Start the bridge to check pairing.

Keep this screen private. In Apple Home: + → Add Accessory. This bridge is not Apple-certified.

Reset HomeKit pairing

This removes this bridge's pairings after creating a private backup. Remove it from Apple Home first. Your light selections and states remain. Quit and reopen the application afterward.

Settings

Keep the existing HomeKit port when upgrading. 51826 is the default, not a requirement. Use 51827 if another bridge already occupies 51826.

Uses a user-level Startup launcher; no administrator privileges or firewall changes. OpenRGB must start separately and may need elevated PawnIO access.

Changing the backend replaces light selections. Changing a whole device to zones creates new HomeKit accessories; existing whole-device UUIDs remain unchanged otherwise.

Diagnostics

If RAM is missing from OpenRGB itself, check PawnIO and run OpenRGB as administrator. Close iCUE and other competing RGB tools. Never expose the SDK server to the internet.
